# TP JPA : Requetes Avancees, Criteria API et Pagination

Projet de gestion de salles illustrant :
- Requetes JPQL avec sous-requete de chevauchement horaire (disponibilite).
- Recherche multi-criteres dynamique avec l'API Criteria.
- Pagination des resultats (setFirstResult / setMaxResults) et calcul du nombre de pages.

## Execution
```bash
mvn clean compile exec:java
```
